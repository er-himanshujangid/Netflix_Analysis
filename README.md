# Netflix Data Analysis

## 📌 Project Overview

Netflix Data Analysis is an end-to-end Data Analytics project focused on analyzing Netflix movies and TV shows to identify content trends, genres, ratings, release patterns, and other meaningful insights.

The project follows a complete analytics workflow, starting with an Excel dataset, followed by data cleaning and EDA using Python, SQL analysis using PostgreSQL, and interactive dashboard development using Power BI.

## 🛠️ Tools & Technologies

* **Excel** – Raw dataset
* **Python** – Data cleaning and EDA
* **Pandas & NumPy** – Data manipulation and preprocessing
* **Jupyter Notebook** – Analysis environment
* **PostgreSQL** – Database management
* **SQL** – Data analysis and business queries
* **Power BI** – Interactive dashboard and visualization

## 🔄 Project Workflow

### 1. Excel → Jupyter Notebook

Imported the raw Netflix dataset from Excel into Jupyter Notebook and examined its structure, columns, data types, missing values, and duplicates.

### 2. Data Cleaning & EDA — Python

Used Pandas and NumPy to clean and preprocess the dataset, handle missing values and duplicates, correct data types, and perform exploratory data analysis to identify important patterns and trends.

### 3. PostgreSQL & SQL Analysis

Loaded the cleaned dataset into PostgreSQL and wrote SQL queries to analyze Netflix content, including movies vs TV shows, genres, ratings, release years, countries, and content distribution.

### 4. Power BI Dashboard

Connected PostgreSQL with Power BI and created an interactive dashboard with KPIs, charts, slicers, filters, and content analysis to present key insights.

## 🎯 Project Objective

**Excel → Python → EDA → PostgreSQL → SQL → Power BI → Business Insights**

This project demonstrates practical skills in **Excel, Python, Pandas, NumPy, SQL, PostgreSQL, and Power BI**, showcasing a complete end-to-end data analytics workflow.
